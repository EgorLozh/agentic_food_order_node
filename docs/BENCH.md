# Замеры времени ответа (прод, 194.67.124.139)

Два независимых замера на живом проде:

1. **E2E через Telegram** — тестовый аккаунт (Telethon, `food-order-bench` из Python-проекта) пишет
   боту @testfeedmer_bot реальные сообщения и мерит время до ответа. Это ровно то, что видит клиент.
2. **Внутренний** — `npm run bench:agent` на сервере: тот же `BotService` без Telegram, зато с разбивкой

Конфигурация: `deepseek/deepseek-flash`, кафе по умолчанию 68, трафик бота через AmneziaWG.
Сырые отчёты — `bench/reports/`.

## Выводы

- **Задержку делает модель, а не сервер.** Чистый ping модели 1.10 c, а раунд в агенте 2.23 c:
  каждый раунд тащит в prompt системную инструкцию + историю + все описания 12 инструментов.
- **Ход = раунды × 2.23 c + ~0.1 c на БД и форматирование.** Медиана 2.5 раунда даёт 4.8–5.5 c —
  это и есть наблюдаемые 4.7 c p50 по текстовым ходам.
- **Telegram добавляет всего 0.3–0.5 c** (видно по `/start` и `/cancel`: там нет модели, p50 0.34–0.35 c).
  Туннель AmneziaWG на это не влияет — DeepSeek и так ходит напрямую по скорости.
- **Хвост 9–14 c** — ходы с 3–4 раундами (сложная реплика «всё сразу», замена позиции,
  уточнение по неоднозначному названию). Клиент ждёт ≤ 10 c в 90 % ходов.
- Полный заказ из 6 реплик — около 30 c суммарно, но это не одна пауза: клиент ждёт максимум один ход.

## Что ускорит ответ (по убыванию эффекта)

1. **Меньше раундов.** Типовой ход — «сделал `set_items` → прочитал сводку → ответил».
   Если инструмент сразу отдаёт сводку, ход схлопывается с 3 раундов до 2: −2.2 c на каждом ходу.
2. **Короче история в prompt.** `DIALOG_HISTORY_LIMIT=6` → 4 (уточнения и так живут в состоянии,
   а не в истории) — раунд дешевеет у всех ходов, кроме первого.
3. **Кэш меню в процессе.** `get_menu` тянет 998 строк прайса из БД каждый раунд; кэш на 30–60 c
   с инвалидацией по времени экономит 50–150 мс на раунд (модель всё равно дороже, но бесплатно).
4. **Статусы в черновике** уже включены (`TELEGRAM_DRAFT_STREAM=1`): «Думаю… → Ищу в меню…» —
   субъективно пауза не читается как зависание. Это не ускоряет, но снимает главную жалобу.
